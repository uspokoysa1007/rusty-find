# ⚡ rusty-find

[![Rust](https://img.shields.io/badge/Language-Rust%202021-orange.svg)](https://www.rust-lang.org/)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey.svg)]()

> Сверхбыстрый многопоточный консольный поисковик файлов и содержимого на Rust с поддержкой параллелизма через **Rayon** и удобным CLI на **Clap**.

```text
========================================
       ⚡ RUSTY-FIND SEARCH TOOL ⚡       
========================================
🔍 Поиск в директории: .
📝 По шаблону имени:   main
📎 Расширение:         .rs
----------------------------------------
📄 .\rust-port-scanner\src\main.rs [5.3 KB]
📄 .\rust-sysmon-tui\src\main.rs [8.1 KB]
📄 .\rusty-find\src\main.rs [6.4 KB]
----------------------------------------
✨ Найдено: 3 файлов (просканировано: 2236) за 68.19 мс
```

## ✨ Возможности
- 🚀 **Максимальная скорость:** автоматическое распределение нагрузки по всем ядрам процессора с помощью `rayon`.
- 📁 **Поиск по имени и маске:** поддержка регистронезависимых совпадений и Regex-шаблонов.
- 📎 **Фильтрация по расширению:** мгновенная фильтрация (например, только `.rs`, `.json`, `.ts`).
- 🔎 **Поиск внутри файлов (grep):** поиск текста внутри документов с выводом номеров строк и контекста.
- ⚖️ **Фильтры по размеру:** отбор файлов больше (`--min-size-kb`) или меньше (`--max-size-kb`) заданного размера.
- ⏱ **Статистика в реальном времени:** точное время сканирования с миллисекундной точностью.

## 🚀 Быстрый старт

### 1. Готовый бинарник
Скачайте архив из раздела [Releases] или используйте бинарник из папки `release-package/`:
```powershell
.\rusty-find.exe --help
```

### 2. Сборка из исходников
```powershell
git clone <URL_РЕПОЗИТОРИЯ>
cd rusty-find
cargo run --release -- --help
```

---

## 📖 Примеры использования

```powershell
# 1. Поиск всех файлов с расширением .rs
.\rusty-find.exe -e rs

# 2. Поиск файла по части имени в текущей папке
.\rusty-find.exe -n config

# 3. Поиск файлов в конкретной директории
.\rusty-find.exe -p "C:\Projects" -e toml

# 4. Поиск текста внутри файлов (показывает путь, размер и совпавшие строки)
.\rusty-find.exe -c "tokio"

# 5. Поиск файлов размером более 1 МБ (1024 КБ)
.\rusty-find.exe --min-size-kb 1024

# 6. Комбинированный сложный поиск
.\rusty-find.exe -p . -e rs -n "test" -c "assert" --max-size-kb 500
```

## 🛠 Параметры командной строки
| Флаг | Полное имя | Описание |
| :--- | :--- | :--- |
| `-p` | `--path` | Начальная папка сканирования (по умолчанию `.`) |
| `-n` | `--name` | Шаблон или регулярное выражение имени файла |
| `-e` | `--ext` | Расширение файла (без точки, например `rs`) |
| `-c` | `--content` | Текст или регулярка для поиска внутри файлов |
| | `--min-size-kb` | Минимальный размер файла в килобайтах |
| | `--max-size-kb` | Максимальный размер файла в килобайтах |
| `-h` | `--help` | Показать справку по всем ключам |
| `-V` | `--version` | Показать текущую версию утилиты |
